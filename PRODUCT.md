# AEGIS
Android Evidence & Git Inspection System. Local security evidence workbench for Android packages and public GitHub repositories/source snapshots. Existing Android static analysis, optional consent-based VT/Firebase and optional hosted AI; repository inventory, AST/pattern checks, Semgrep/Bandit, decoding, relationships, coverage, review and exports. No guaranteed safety verdict, complete decompilation or full repository roadmap claims. User wants an immersive project-name/progress intro, a beautiful capabilities landing page with two functional analysis entry points, and a uniform theme across both workspaces. Keep existing data/provider configuration. Code-first is confirmed. Reference beatwave.de5.net supplies bold dark brand presentation and intro motion, not claims or assets.
